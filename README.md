# learning-projects

한준희의 **학습 · 연습 프로젝트 모음**. 개발을 공부하며 만든 프로젝트들을 한 저장소로 묶었습니다.
각 폴더는 개별 저장소의 스냅샷입니다 (원본 저장소의 커밋 히스토리는 각 원본에 남아 있습니다).

## 구성
| 폴더 | 내용 | 스택 |
|---|---|---|
| [coding-test](coding-test) | 알고리즘 · 코딩테스트 풀이 (Programmers 등) | Java |
| [spring-book](spring-book) | Spring 교재 스터디 (MVC · JDBC · MyBatis 등) | Java · Spring · Oracle |
| [book-example](book-example) | jojoldu '스프링부트와 AWS로 혼자 구현하는 웹서비스' 예제 | Spring Boot · JPA |
| [flutter-app](flutter-app) | Flutter 입문 앱 | Dart · Flutter |
| [slack-bot](slack-bot) | Slack 봇 실습 (초기 스텁) | - |

> 전부 학습 목적 코드이며 토큰 · API 키 · 실제 비밀번호 등 민감정보는 없습니다.
> (spring-book의 DB 설정은 더미 `test`/`1234` + 로컬 VM 주소뿐입니다.)
